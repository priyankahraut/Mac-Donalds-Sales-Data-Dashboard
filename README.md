## Project Overview
This project showcases an interactive Sales MIS Dashboard built using Microsoft Excel to analyze McDonald's sales performance, profitability, and customer satisfaction.

The dashboard provides a visual overview of key business metrics, helping users understand sales trends, monitor performance, and gain insights into different markets.

## Dashboard Preview

![McDonald's Sales Dashboard](dashboard.png)

## Key Performance Indicators (KPIs)
- **Total Sales:** $2,544
- **Total Profit:** $890
- **Total Customers:** 87
- **Sales Performance:** 85%
- **Profit Performance:** 89%
- **Customer Performance:** 87%

## Dashboard Features
- Sales, profit, and customer KPI tracking.
- Customer satisfaction analysis using a radar chart.
- Monthly sales trend comparison (2025–2026).
- Country-wise sales performance analysis.
- Interactive charts and visual reports.
- Easy-to-understand business performance overview.

## Tools & Technologies
- Microsoft Excel
- Excel Formulas
- Data Cleaning
- Pivot Tables
- Data Visualization
- Charts & Graphs
- MIS Reporting

## Key Insights
The dashboard helps analyze monthly sales trends, compare yearly performance, identify high-performing countries, and monitor customer satisfaction across different service parameters.

## Project Objective
To transform raw sales data into meaningful business insights through Excel-based MIS reporting and interactive data visualization.
